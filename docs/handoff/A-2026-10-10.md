## Tested
Real, on Linux gcc in a sandbox: full non-slow ctest 84/84, `ctest -L slow` 2/2. New suites: library (8 cases), profiles (27), capability (7), migration (5), settings v2 (8). The v1 survival test loads a real v1 document emitted by the pre-change settings code (commit 9b76ef6) and checks selection, keep-ready, model dirs, roots and bindings survive.
Not run: Windows, MSVC, CI, CUDA, any GPU, any real model. CI has not run on this branch.
Fixture-based: library tests use generated fixture GGUFs, not real models.

- Profile `speculation.max_q` (4) differs from legacy `advanced.default_q`; the legacy path keeps its control.
- Residual risks from the Opus review are listed in ADR 0407.
