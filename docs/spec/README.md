# ClusterLM project spec (reference copy)

progress lives in [../status.md](../status.md). The unsplit original is [clusterlm-project-spec.md](clusterlm-project-spec.md)
(also at `/mnt/project-files/spec/clusterlm-project-spec.md` in the Claude project).

| File | Content |

| [01-product-vision.md](01-product-vision.md) | what ClusterLM is, naming |
| [02-requirements-detail.md](02-requirements-detail.md) | profiles, placement, library, backends, API, tools, MCP, UI, resources, scheduling, security, lifecycle, packaging, Strata |
| [03-workstreams.md](03-workstreams.md) | workstream table and dependency order |

| [07-thread-kickoffs.md](07-thread-kickoffs.md) | the kickoff prompt of each workstream thread |
